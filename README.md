# JobMandu - Job Portal Web Application
A web-based job portal for assigment built with Python Flask, MySQL, HTML, CSS, and Bootstrap 5.

## How to Run
1. Clone the repo: git clone https://github.com/suyog-max/jobmandu.git
2. Install packages: pip install flask flask-wtf flask-mysqldb wtforms email-validator
3. Set up MySQL database (see app.py for config)
4. Run: python app.py
5. Open: http://localhost:8000
